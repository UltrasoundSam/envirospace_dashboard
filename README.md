# EnviroSpace Dashboard

The EnviroSpace Dashboard provides data ingestion, storage, and visualisation services for the EnviroSpace environmental monitoring platform.

EnviroSpace monitors environmental conditions such as temperature, humidity, ambient noise, and light levels in physical spaces. Sensor nodes publish readings via MQTT, which are consumed by this application and stored in a MariaDB database for analysis and display.

## Features

- MQTT data ingestion
- Secure MQTT connectivity using TLS
- MariaDB data storage
- Historical environmental data analysis
- Live and historical dashboards
- Multi-location support
- Environmental trend visualisation
- Extensible architecture for future sensor types

## System Architecture

```text
EnviroSpace Monitor
       │
       │ MQTT/TLS
       ▼
   Mosquitto Broker
       │
       ▼
 EnviroSpace Dashboard
       │
       ├── Data Ingestion
       ├── Database Storage
       └── Dashboard Interface
       │
       ▼
      MariaDB
```

## Database Structure

The application currently uses the following core tables:

### locations

Stores monitored locations.

| Field | Description |
|---------|-------------|
| id | Unique location identifier |
| room_name | Human-readable room name |
| room_code | Unique room identifier |

### readings

Stores environmental measurements received from sensor nodes.

| Field | Description |
|---------|-------------|
| id | Reading identifier |
| device_id | Sensor device identifier |
| recorded_at | Reading timestamp |
| temperature | Temperature (°C) |
| humidity | Relative humidity (%) |
| pressure | Atmospheric pressure (hPa) |
| noise | Ambient noise level |
| light_lux | Light intensity (lux) |

## MQTT Topics

Sensor readings are published to topics using the following convention:

```text
envirospace/<location>
```

Example:

```text
envirospace/room101
```

Payload format:

```json
{
  "device": "enviro-pi-001",
  "timestamp": "2026-11-20T17:30:00Z",
  "temperature": 22.4,
  "humidity": 48.6,
  "noise": 41.2,
  "pressure": 1024.2
  "light": 315
}
```
